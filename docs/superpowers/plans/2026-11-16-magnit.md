# Magnit Tech Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Добавить Magnit Tech по ссылке пользователя в существующий утренний мониторинг.
**Architecture:** `magnit.py` использует публичный API сайта и общий `career.collect`; ссылки в письме ведут на обычные карточки.
**Tech Stack:** Python, requests, BeautifulSoup, unittest.
**Spec:** Повторить согласованную схему новых компаний из `docs/company-sites-design-2026-11-16.md` для конкретного сайта пользователя https://magnit.tech/vacancies.

## Global Constraints

- Только утро, первый обход14 дней при известной дате, далее seen; без даты текущие активные карточки.
- Только явная удалёнка по `work_formats`, подтверждённая в подробной карточке; офис/пропуск формата исключаются.
- Архивные/неопубликованные карточки не отправлять; сохранять текущие фильтры/дедуп/отметки.
- Никаких писем и записей в рабочую SQLite при проверке, никаких новых зависимостей.

## Review Focus

- API имеет `id` и `foreign_id`; сайт и detail API используют `id`.
- Список не содержит всех полей описания и статуса; перепроверять карточку.
- Несовпадающая пагинация и метаданные означают ошибку источника.
- Футер/соседние вакансии и общие слова не подтверждают удалёнку.
- Дата отсутствует в текущем API — не заменять временем сбора.

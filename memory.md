## Цель

Каждое утро, пока я включаю компьютер (9:00–9:30), агент собирает свежие вакансии
**продуктового аналитика и аналитика данных**, которые можно делать **удалённо из России**,
и к 10:00 присылает одно письмо. Дальше по плану — черновики сопроводительных и отклик в одно нажатие.

## Принятые решения (19.10.2026)

**Источники**
- Telegram (публичные, читаем через веб-превью `t.me/s/<канал>`, без аккаунта и Telethon):
  `nodatanojobs`, `careerstation_analyst`, `codeworkshopru`, `HR_CATExpert`, `talentmove_channel`.
  Все включены, чтобы набрать статистику; через месяц решаем по цифрам (`python main.py --stats`).
- Сайты: только **jabka.work** (ссылка поиска «Аналитик» + удалёнка). Третьего сайта не будет.
- **Hirify** — отложен. Есть официальный доступ (REST API / MCP / CLI) в тарифе Plus за 399 ₽/мес,
  парсить сайт они просят не надо. Новые вакансии приходят вебхуком → нужен публичный адрес.
- **LinkedIn** — НЕ скрапим (риск бана, нужен VPN). Только через почту:
  подписки на вакансии (Product Analyst / Data Analyst, Remote, ежедневно) и колокольчик
  «все публикации» на профилях друзей + отправка этих уведомлений на email.
  Источник в коде есть, но выключен до недели проверки, что уведомления реально доходят.
- hh.ru в агент не входит — там отклики уже разосланы вручную.

**Отбор**
- Роли: продуктовый аналитик, аналитик данных (для него в тексте обязателен SQL / Python / Excel).
- Отсекаем junior и стажёров.
- Формат: «можно удалённо из РФ» — да / нет / не указано. «Не указано» не выкидываем, а показываем отдельным блоком.
  «Удалёнка, но не из РФ», «кроме России», офис, гибрид, релокация → отсев.
- Посты от знакомых (LinkedIn) — отдельный блок наверху, фильтр мягче: можно попросить рекомендацию.
- **Подборки не теряем** (пример — «Подборка актуальных вакансий за неделю», CareerStation, 17 августа):
  разворачиваем ссылки в отдельные вакансии, уже виденные пропускаем, невиденные посты открываем целиком.

**Доставка и запуск**
- Одно HTML-письмо на почту. Gmail или Яндекс — одинаково просто (пароль приложения);
  берём ящик, на который зарегистрирован LinkedIn. Telegram-бот — позже, как короткое уведомление.
- Запуск локально на Windows: Python + LM Studio (Qwen). Не облако: российские сайты могут
  резать облачные адреса, плюс бесплатно.
- Задача Планировщика Windows: через 3 минуты после входа в систему, раз в день
  (второй вход в тот же день письма не шлёт).

**Принципы (из статьи Anthropic «Building effective agent automations», 08.10.2026)**
1. Читать от закладки, а не «за последние 24 часа».
2. Упавший источник ≠ спокойный день: плашка в письме, закладка не двигается.
3. Состояние меняется только после того, как письмо подтверждённо ушло.
4. Настройки перечитываются каждый запуск; без них — остановка, а не «по умолчанию».
5. Минимум прав: только чтение + одно письмо себе.
6. LLM решает одну узкую задачу (разметить пост в JSON), всё остальное — код.
   Локальная 8–14B не тянет навигацию и контроль состояния (опыт с nanobrowser + Qwen3-8B: зацикливалась).

**Что сознательно НЕ делаем**
- Автоотклики без моего просмотра (мусорные отклики, антибот, риск блокировки аккаунтов).
- Сообщения рекрутерам в Telegram с моего аккаунта.

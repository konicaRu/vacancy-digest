# More companies Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans, implement task-by-task with RED → GREEN checks.

**Goal:** Подключить следующую доступную партию компаний к существующему утреннему дайджесту.
**Architecture:** Сохранить согласованный контракт career.collect и оформление письма; новые адаптеры возвращают Item и SourceResult, ошибки не маскируют отсутствие вакансий.
**Tech Stack:** Python, requests, BeautifulSoup, unittest; без новых зависимостей и аккаунтов.
**Spec:** docs/company-sites-design-2026-11-12.md, продолжение по просьбе пользователя «добавляй еще компаний».

## Global Constraints

- Даты из источников, текущие фильтры и отметки; новые источники только утром, dry-run в любое время.
- Не менять уже подготовленную правку дат в письме и рабочую историю при проверках.
- Яндекс сейчас возвращает CAPTCHA; не подключать источник как якобы успешно прочитанный.
- 2ГИС дважды не ответил при проверке; оставить в бэклоге.
- Никаких коммита, push или новой рассылки без отдельного запроса.

## Review Focus

- VK возвращает next по HTTP: оставить только доверенный host/path и перевести на HTTPS, проверить тестом.
- МТС игнорирует page/offset в HTML: подтвердить реальную пагинацию API до подключения.
- Формат и дата принадлежат самой вакансии; меню и похожие вакансии не входят в текст.
- При сбое нужного описания вернуть SourceResult без закладки и элементов.
- Пустой подтверждённый JSON означает успешную пустую выдачу; неизвестная страница — ошибку.

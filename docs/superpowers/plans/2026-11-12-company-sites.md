# Career sites Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Добавить Хабр Карьеру, Авито и Aviasales в утренний дайджест.
**Architecture:** Три адаптера отдают SourceResult; общий небольшой сборщик обрабатывает новые карточки и описания. Текущие классификация, дедуп, Store и отправка используются без изменения контрактов.
**Tech Stack:** Python 3.10+, requests, BeautifulSoup, unittest.
**Spec:** docs/company-sites-design-2026-11-12.md (согласован пользователем «делай»).

## Global Constraints

- Без новых зависимостей, автооткликов и браузерной автоматизации.
- Новые источники обходятся утром; dry-run проверяет их в любое время.
- Первое чтение: последние 5 дней при известной дате, иначе активные вакансии.
- Состояние только после отправки; ошибки источника не маскируются пустой выдачей.
- Сохранить существующие незакоммиченные изменения; без коммита и push.

## Review Focus

- Меню и общие блоки сайта не должны влиять на формат вакансии: тест полного описания.
- Пустая выдача отличается от изменившейся вёрстки: отдельные тесты.
- Сбой описания не помечает вакансию просмотренной: тест SourceResult без состояния.
- Одинаковые ссылки и повторные страницы не вызывают бесконечный обход: тест пагинации.
- Вечерний запуск и dry-run различаются: тест реального collect_all с локальным fetch.

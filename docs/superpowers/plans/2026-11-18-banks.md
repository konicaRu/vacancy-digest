# Bank career sources Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Подключить Т-Банк и Альфа-Банк к дайджесту с подтверждённой удалёнкой.
**Architecture:** Два адаптера поверх career.collect. Т-Банк переводит URL пагинации в публичные поисковые POST, Альфа-Банк читает GET API. Общий fetch поддерживает необязательный json.
**Tech Stack:** Python, requests, BeautifulSoup, unittest.
**Spec:** docs/superpowers/specs/2026-11-18-banks-design.md

## Global Constraints

Текущие фильтры и расписание; TLS проверять; рабочее состояние и почту не менять.

## Review Focus

- Офис/гибрид и упоминание удалёнки в свободном тексте не заменяют метку карточки.
- Ошибки API и пустые неполные ответы не считаются успешным пустым каталогом.
- Повтор/лимит страниц видимы как предупреждение; сбой деталей не двигает закладку.
- Архив, внутренние карточки и подмена идентификатора не попадают в письмо.
- POST payload переносит поиск и offset, GET источники работают по-прежнему.

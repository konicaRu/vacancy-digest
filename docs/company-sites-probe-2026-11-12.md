# Проверка карьерных сайтов — 12.11.2026

Проверено обычным `requests.get` через Python проекта, таймаут 18 секунд.
Это состояние доступа с текущего компьютера и сетевого маршрута, а не постоянное свойство сайта.
Полный диагностический результат: `out/company-sites-probe.json` (локальный, вне Git).

| Результат | Сайты |
|---|---|
| HTTP 200, найдены ссылки с названиями вакансий аналитиков | Хабр Карьера, Авито, Aviasales, СберЗдоровье на Хабре |
| HTTP 200, требуется изучение данных и загрузки списка | VK, Сбер, 2ГИС, X5, Магнит, МТС, МегаФон, Яндекс |
| HTTP 403 | Ozon Tech, Купер, Газпромбанк, ВкусВилл, Tele2, Билайн |
| Ошибка TLS | Альфа-Банк, Т-Банк |
| HTTP 404 | Dodo Brands по сохранённому адресу Huntflow, Самокат по сохранённому адресу hh |

Страницы Lamoda, Wildberries и Okko на Хабре отвечают 200; наличие нужных вакансий отдельно не подтверждено.
Ответ 200 сам по себе не подтверждает, что парсер сможет получить вакансии.
Ссылки на hh по действующему правилу проекта не подключаем.

## Предлагаемая первая партия

Хабр Карьера, Авито и Aviasales: карточки присутствуют в HTML, можно использовать существующий стек requests + BeautifulSoup.
Для Хабра проверена выдача `?q=analyst&type=all&remote=true`: содержит названия, компании, грейд и признак удалёнки.
Нужны также русские запросы; ограничения по стране проверять по полному описанию подходящей вакансии.

Сохранить текущие правила отбора, дедупликации и отметок. Новые источники должны различать пустую выдачу и ошибку разбора;
состояние, как и сейчас, записывать только после успешной отправки письма.
Частота для карьерных сайтов по бэклогу — один утренний проход; существующие источники продолжают работать утром и вечером.

Другой вариант — сразу разбирать API, JavaScript и ограничения всех сайтов первой очереди. Он расширяет охват,
но делает первую поставку существенно больше. Пользователь выбрал первую партию: Хабр Карьера, Авито и Aviasales.
Подключение реализовано и проверено по `docs/company-sites-design-2026-11-12.md`.
Итоговый сбор: три источника без ошибок и предупреждений, 16 подходящих и 7 с неуказанным форматом
по текущим правилам профиля; рабочая история отправок при этой проверке не учитывалась.

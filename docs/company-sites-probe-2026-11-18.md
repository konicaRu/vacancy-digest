# Следующие корпоративные сайты — проверка 18.11.2026

Проверены 12 компаний обычными HTTPS-запросами с проверкой TLS. Критерий рекомендации:
есть каталог, конкретная активная аналитическая карточка открывается, есть описание,
возможность отклика и разрешённая удалёнка. Один HTTP 200 без карточек недостаточен.
Поисковая выдача использовалась для навигации, не заменяла локальную проверку карточки.

## Рекомендуемая партия

### Точка Банк

Каталог https://hr.tochka.com/vacancies/it/remote-work/ — HTTP 200, три аналитические роли:
«Аналитик данных», «Мидл+ продуктовый аналитик», «Senior продуктовый аналитик».

Проверенная карточка https://hr.tochka.com/vacancies/catalog/middle_analyst/ — HTTP 200,
заголовок «Мидл+ продуктовый аналитик», кнопки «Откликнуться», отдельная метка «Удалённо».
В условиях: удалёнка или офис на выбор, ходить в офис необязательно. В требованиях SQL,
Power BI/аналоги, продуктовая аналитика от четырёх лет; зарплата до390000₽ до налогов.

Ограничения проверки: с обычным certifi SSLCertVerificationError, с уже проверенным официальным
CA из out/tls-diagnosis/probe-bundle.pem — каталог и карточка200. verify=False не применялся.
Первый параллельный запрос деталей дал таймауты; повтор одной карточки успешен. Две другие
карточки присутствуют в каталоге и похожих вакансиях, но их отдельные GET пока не подтверждены.
При подключении нужен дополнительный точный origin hr.tochka.com в существующем CA-адаптере.

### Островок

Каталог https://career.ostrovok.ru/vacancy — HTTP 200.

Открыты три конкретные карточки, каждая HTTP 200, actual=true в Next.js и есть отклик:

- https://career.ostrovok.ru/vacancy/3484 — Senior Product Analyst (B2C Hotels).
  В условиях этой карточки свободный выбор удалёнки/офиса; SQL, Python, A/B, BI, от3лет опыта.
- https://career.ostrovok.ru/vacancy/3473 — Product Analyst (Content).
  В условиях этой карточки удалёнка/офис на выбор; SQL, Python, A/B; опыт от1года, без junior-метки.
- https://career.ostrovok.ru/vacancy/3486 — Senior Pricing Analyst.
  Активна, но удалёнка в условиях не подтверждена; также есть управление небольшой командой.
  В текущую рекомендацию подходящих вакансий не включать.

Для Островка обычного make_session достаточно, дополнительного CA не потребовалось.
В проверенных продуктовых карточках нет явного запрета работы из РФ; юридические условия
работы из РФ не проверялись отдельно. Доступный московский офис сам по себе удалёнку не доказывает:
основание — условия конкретных вакансий.
